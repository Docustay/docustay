# Change order template

A written change to an existing agreement: what is changing, how the cost and time were worked out, and the new total and finish date.

Use it when the client asks for something the first agreement did not cover. It records what changes and what it costs.

## Who signs

- Provider
- Client

## Before you send

- Name the agreement it changes.
- State the new price and the new date.
- Say that everything else stays the same.

## The facts

- 3 pages
- 24 fields
- About 9 minutes to fill in
