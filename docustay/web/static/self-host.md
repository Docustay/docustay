# Run Docustay on your own server

Self-hosted e-signature: the same software as the hosted service, on a machine you control. Licensed under the AGPL-3.0. Community is free. Self-host Pro is $390 a year per install, for your own business. A commercial licence, from about $3,000 a year, covers embedding, white-label and resale.

Three commands: `cd docustay`, `./init.sh`, `docker compose up -d`, then open http://localhost:8080/setup. A running install idles at about 1 GiB of memory; building the image needs more than 3.8 GB.
