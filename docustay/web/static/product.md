# From a file to a signed, sealed copy

Say who signs, prepare the document, check it and send it. Everyone gets the signed copy and its certificate.

## Five steps from a file to a signed copy.

1. **Who signs**: Names and order
2. **Prepare**: Template or file
3. **Details**: Subject and message
4. **Check**: A last look
5. **Send**: Email or in person

## A lease addendum, from start to finish.

**You send it.** Pick the lease addendum template, add the tenant and the landlord, and set the tenant to sign first.

**They sign it.** The tenant opens the link on a phone, signs, and the landlord is told it is their turn.

**You keep it.** Both of you get the sealed PDF and a certificate that lists each signature with its time.

## Questions

**Do I need to install anything?**

No. Docustay runs in the browser, and the people who sign need only the link.

**What if someone is not sure how to sign?**

The signing page shows how many fields are left and jumps to the next one. A person can also decline and say why, or save and come back later.

**What can I send besides a template?**

A PDF. Docustay only accepts PDF files.
