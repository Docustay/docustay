# Start from a finished document.

Pick one of 54 built-in templates (24 for documents, 30 for forms), or save your own file as a template once and send it as often as you like.

## Real pages you can flip through first.

Every template shows its actual pages and where each field sits before you use it.

- [Offer letter template](/templates/offer-letter-template)
- [Service agreement template](/templates/service-agreement-template)

## What a template carries.

**Roles.** Name the people by role, such as Tenant, Landlord or Witness. Add approvers, viewers, a copy-only role and an assistant who fills in fields for someone else.

**Fields.** Signature, initials, date, text, checkbox, dropdown, picture, file upload, stamp and payment. Each belongs to one role and can be required.

**Reuse.** Send it from the app, from your code through the API, or from a link that lets a person start their own copy.

## Turn your file into a template.

Upload a PDF, or type text tags where the fields belong, and Docustay places them for you.

- Drop on the fields you need, or write them into the file as text tags.
- Send to a list from a spreadsheet on Pro; one bad row never spoils the rest.
- Every template can be sent in any of the 14 languages the signer picks.

- **Templates**: 54 built-in, plus your own
- **Languages**: 14 for the signer
- **Upload**: PDF files only

## Type the field where it should go.

A text tag is the field written inside your own text. Docustay finds each tag and places a field there.

```
The Buyer will pay {{Price;type=number;role=Buyer}} dollars on
{{Closing date;type=date;role=Seller}}.

{{Buyer signature;type=signature;role=Buyer}}
{{Seller signature;type=signature;role=Seller}}
```

## Questions

**Can I change a template?**

Yes. In your workspace it is your own copy. Change the text or the fields and save. The original is never changed.

**Is a template legal advice?**

No. It is a starting point in plain words. Change what does not fit before you send it.

**Can Scribe write one for me?**

Yes. Describe what you need and review what Scribe builds before anything is sent.
