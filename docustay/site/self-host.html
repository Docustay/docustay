Run Docustay yourself

One command to create your settings, one to start it. Your documents and your email stay on your server.

Install

git clone <the Docustay repository>
cd docustay/docustay
./init.sh
docker compose up -d

Then open http://localhost:8080/setup, enter the setup token that ./init.sh printed, and create your owner account.

Email

Until email works, Docustay says "Email isn't set up" and will not send a document, so nothing disappears silently. Put your own Resend key in .env, or enter your own SMTP server under Settings → Email, send yourself a test, and you're ready.

What is inside

Six containers: your database, your file store, a PDF converter, the app, the web app and the worker. There is nothing of ours in it: every key and certificate is created on your machine the first time it starts. Once a day it sends an anonymous usage ping (a random install id, the version and five counts, never content) — switch it off with DOCUSTAY_TELEMETRY=off, or send a report by hand. Pro is a closed add-on: your install downloads it with your licence key the first time it starts (the key is checked on our side, and the download is for your install only), then checks the licence once a day and keeps working up to 30 days offline. When the licence ends the install is the Community build again and nothing is deleted.
