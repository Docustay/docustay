# @docustay2026/mcp

A Model Context Protocol server for Docustay: lets an AI assistant create, send, track and sign documents through your Docustay workspace.

```sh
npx @docustay2026/mcp
```

Set `DOCUSTAY_API_KEY` (create one in Settings, Developers) and, for a self-hosted install, `DOCUSTAY_BASE_URL`. Documentation: https://docustay.app/developers
